# My Todo List

A responsive, accessible to-do list built with semantic HTML, CSS, and vanilla JavaScript. Tasks are stored in your browser's local storage, so your list stays on this device after you close or refresh the page.

## Run locally

Open `index.html` in a modern web browser. No install, build step, server, or account is required. The Google Fonts link is optional; the app falls back to system fonts if you are offline.

## Use

- Type a task and press **Enter** or select the **+** button to add it.
- Use the check button to mark a task complete or active.
- Select **Edit** to change a task. Press **Enter** to save or **Escape** to cancel.
- Choose **All**, **Active**, or **Completed** to filter the list.
- Select **Clear completed** to remove every completed task.

Tasks are kept in local storage under `my-todo-list.tasks.v1`. They are specific to the browser and device where you opened the app.
